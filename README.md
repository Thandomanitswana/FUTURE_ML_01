# 📊 Sales Forecasting Dashboard (Power BI + Python)

## 📌 Project Overview
This project focuses on building a **sales forecasting solution** to help support data-driven business decisions.  
It combines **Python for data preparation and forecasting** with **Power BI for visualization and insights**.

The goal of this project was to transform raw sales data into meaningful insights and future predictions that can help a business owner plan ahead.

---

## 🚀 Features
- 📈 Sales forecasting using time-series techniques  
- 📊 Interactive Power BI dashboard  
- 🔄 Rolling average to analyze trends over time  
- 📅 Monthly sales trend analysis  
- 🎯 KPI cards (Total Sales, Average Sales, Maximum Sales)  
- 🔍 Date filter for dynamic exploration  

---

## 🛠️ Tools & Technologies
- **Python** (Pandas, NumPy, Matplotlib)
- **Power BI**
- **DAX (Data Analysis Expressions)**
- **Jupyter Notebook**

## ⚠️ Challenges & Learnings
As someone still new to Python, one of the biggest challenges I faced was **data cleaning**.

I learned that:
- Data cleaning is not a single-step process  
- Different datasets require different approaches  
- Handling missing values, formatting, and inconsistencies is crucial before analysis  

This project helped me better understand the **importance of data preparation** in any data analysis workflow.
